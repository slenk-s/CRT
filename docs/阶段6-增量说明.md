## 2. 设计要点

- **接入方式**：优先 `import wb_mail.mes_api`（同机部署）；加载时若存在 `wb_mail.mes_env.load()` 则调用（端点已由环境变量预置，不覆盖）。`WB_MAIL_PATH` 可指定包目录加入 `sys.path`。
- **原样透传**：`fetch_fields(batch, with_side_label=True)` / `fetch_fields_by_bom(bom)` 返回的**有序** `dict[str,str]` 原样输出，键名即中文字段名，不增删、不改序（Python 3.7+ dict 保序）。
- **可插拔降级**（`WB_SOURCE`）：
  - `auto`（默认）：真实 `mes_api` → 不可用回退 `http` → 都没有则不可用；
  - `mes` 强制真实；`http` 走 `WB_BY_BATCH_URL/WB_BY_BOM_URL`；`mock` 假数据（开发自测）；`off` 一律 503。
- **失败隔离**：多批次（逗号/换行/分号分隔）逐条查询，单条失败 → 该条 `ok=false` + `error`，不遮蔽其他条目。
- **降级提示**：端点缺失 / 包未安装 → 503「数据源未配置，请联系管理员」；`/api/wb/status` 供前端静默探测。
- 需登录访问。
