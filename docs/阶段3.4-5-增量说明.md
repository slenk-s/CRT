## 1. 阶段 3.4 · 管理端（仅 admin，软删）

新增 `backend/app/routers/admin.py`，全部接口挂在 `/api/admin` 且依赖 `require_admin`（非 admin → 403，未登录 → 401）。所有变更写 `audit_log`。

| 资源 | 接口 | 关键行为 |
|---|---|---|
| 线体 | `GET/POST /lines`、`PUT/DELETE /lines/{id}`、`POST /lines/import` | 重复唯一键 409；软删项再建=**复活**；改名冲突 409；`import` 支持「车间,线体」多行（Tab/中英文逗号/分号/空白分隔），返回 `added/reactivated/skipped` |
| 工位 | `GET/POST /stations`、`PUT/DELETE /stations/{id}` | 同上，软删 |
| 检查项 | `GET/POST /check-items`、`PUT/DELETE /check-items/{id}` | 唯一键 `(station,item)`；工位须存在且启用；软删 |
| 用户 | `GET/POST /users`、`PUT /users/{emp_id}` | 初始/重置口令强制改密；**自保护**：不能停用/降级当前登录账号 |

**软删语义**：字典读取（`/api/dict/*`）只返回 `active=1`；历史转场记录仍可见原线体/车间；停用线体不能再新建转场（400）。

## 2. 阶段 5 · 导出 CSV / 统计

- `GET /api/changeover/export.csv`（`changeover.py`，**注册在 `/{co_id}` 之前**避免路径抢占）：
  - 筛选条件与列表一致（status/line/日期区间/批次关键字/mine），上限 10000 条；
  - **按工位条目（最新版）一行**，字段：日期/车间/线体/批次/工位/版本/勾选结果/备注/文件名/路径/上传人工号/上传人/上传时间；
  - 草稿会话的条目版本列输出「草稿」；
  - 输出 **UTF-8 BOM**（`\ufeff`），`Content-Disposition` 带 `filename*=UTF-8''…`，Excel 打开中文不乱码。
- `GET /api/stats/changeover?days=14`（`routers/reports.py`，**仅 admin**）：返回近 N 天 `{date, changeovers, items}` 折线与线体 Top10，作为前端折线图占位数据源。
