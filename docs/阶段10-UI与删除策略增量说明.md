# 阶段 10 · UI 与删除策略增量说明（2026-10-10）

> 本文记录本轮前端响应式、视觉交互、状态判定与删除策略调整。后端业务主链路（草稿 → 提交 → 版本纠错）保持不变。

---

全项目业务文案与文档统一使用：

- **产线转产**

## 2. 顶部导航与移动端适配

### 2.1 固定规则

- **汉堡菜单：永远最左侧**
- **用户区：永远最右侧**
- 两者位置不随内容、屏幕宽度或菜单展开状态改变。

### 2.2 桌面端

- 显示：汉堡菜单 + 横向导航 + 用户区。
- 完整标题隐藏，避免横向导航拥挤。
- 横向导航承接主菜单入口。
- 顶部背景采用登录页同源风格：深色渐变、动态模糊、呼吸弥散背光。

### 2.3 移动端

- 显示：汉堡菜单 + 用户区。
- 隐藏标题与横向导航。
- 点击汉堡菜单后从按钮附近展开浮层导航。
- 关闭时原路收回。
- 选择菜单项后自动关闭导航。

## 5. 录入页状态判定

### 5.1 业务规则

- 有任意勾选检查项 **或** 已有备注 **或** 已有照片 → `已录`。
- 点开但无勾选、无备注、无照片 → `未录`。

该规则避免仅打开工位详情就把条目计入“已录”。

### 5.2 工位状态图标

- 未录：红色圆环空白图标，颜色 `#f56c6c`。
- 已录：绿色圆环勾选图标，颜色 `#67c23a`。
- 所有工位行统一使用同一套状态图标。

### 5.3 检查项复选框

检查项已从 Element Plus 默认 checkbox 替换为自定义圆形 SVG checkbox：

- 未选中：浅灰蓝背景。
- Hover：浅蓝反馈。
- 选中：主色 `#409eff`，描边与勾线执行绘制动画。
- 勾选/取消时具备平滑过渡。

### 5.4 展开箭头

工位行展开后：

- 右侧 `ArrowRight` 图标旋转 90° 向下。
- 收起后恢复向右。
- 带弹性缓动动画。

## 9. 删除策略变更

### 9.1 字典删除

以下字典项的删除按钮均为**物理删除**：

- 线体：`DELETE /api/admin/lines/{id}`
- 工位：`DELETE /api/admin/stations/{id}`
- 检查项：`DELETE /api/admin/check-items/{id}`

删除后会写入 `audit_log`；已有转产历史记录保留，不再依赖字典行是否软删。

### 9.2 业务记录删除

- 草稿转产会话删除：物理删除会话并清理草稿文件。
- 已提交转产会话：不允许删除，返回 409。
- 已提交条目删除：软删 `is_deleted=1`，保留正式照片与版本历史。

## 11. 功能页标题与工作区拆分

本轮将功能页顶部标题/说明与业务工作区拆开，统一采用转产记录页的层级基准：

1. 标题卡：页面标题 + 页面级说明，使用 `.head-title`。
2. 操作卡：页面级操作按钮，如存在则使用 `.head-actions`，独立成层。
3. 工作区：筛选卡、表格卡、表单卡、统计卡、管理表格等业务内容，独立展示。

已覆盖的功能页：

- 转产记录页：标题卡 + 按钮卡 + 筛选卡 + 表格卡。
- 新建/录入页：标题卡 + 创建态或录入态工作区。
- 转产详情页：标题卡 + 返回/继续录入操作卡 + 详情工作区。
- WB 参数查询页：标题卡 + 查询/结果工作区。
- 统计页：标题卡 + 周期工具卡 + 统计卡片/图表工作区。
- 字典管理页：标题卡 + Tabs/表格工作区。
- 用户管理页：标题卡 + 用户表/弹窗工作区。

全局样式清理：

- 保留并统一 `.head-title` / `.head-actions` / `.page-body`。
- 移除不再使用的 `.head-row` 规则，避免旧标题行样式干扰新结构。

补充调整：

- `.head-title` 统一为全宽标题卡，并设置最小高度：桌面端 `78px`、窄屏 `70px`，用于保持各标签页标题区域视觉等宽、等高。
- 新建转产创建态表单从窄屏 `.mobile` 容器改为 `.page-body`，桌面端铺满工作区宽度。

标题卡统一高度：

- `.head-title` 改为固定高度：桌面端 `78px`、窄屏 `70px`。
- `.head-title h2.title` 统一标题字号、行高与上下边距。
- `.head-title p.hint` 统一为无边距，避免不同页面标题卡高度不一致。
